# Kovara Wallet

![Kovara Wallet brand mark](brand/kovara-wallet.svg)

Kovara Wallet is a desktop Bitcoin wallet based on the open-source Wasabi Wallet codebase. It retains the upstream wallet behavior while applying the Kovara product name and interface identity. This project is independently branded and is not affiliated with or endorsed by the Wasabi Wallet team.

The source code is derived from [WalletWasabi/WalletWasabi](https://github.com/WalletWasabi/WalletWasabi) and retains its upstream license and notices. See [LICENSE.md](LICENSE.md) and [NOTICE.md](NOTICE.md).

## Build from source

Requirements: Git and the .NET 10 SDK.

```powershell
cd WalletWasabi.Fluent.Desktop
dotnet build
```

To run the desktop application:

```powershell
dotnet run
```

The original project documentation remains available at [docs.wasabiwallet.io](https://docs.wasabiwallet.io/).
